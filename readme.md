# Tays Matias Beauty

Site desenvolvido para a designer **Tays Matias**, com o objetivo de apresentar a profissional, seus serviços e facilitar o contato e o agendamento através do WhatsApp.

O projeto também faz parte dos meus estudos em desenvolvimento, permitindo aplicar na prática os conhecimentos adquiridos durante meu aprendizado.

## Funcionalidades

- Apresentação da profissional
- Exibição dos serviços oferecidos
- Layout responsivo para computador e celular
- Animações durante a navegação
- Integração dos serviços com WhatsApp
- Links para WhatsApp e Instagram

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Python
- Flask

## Estrutura do projeto

- `app.py` - aplicação Flask
- `templates/` - páginas HTML
- `static/css/` - arquivos de estilo
- `static/img/` - imagens utilizadas no site

## Status do projeto

Em desenvolvimento.

Atualmente, o site possui sua interface principal, responsividade e integração com o WhatsApp. Novas funcionalidades poderão ser adicionadas conforme a evolução do projeto e dos meus estudos.
